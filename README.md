One sentence, under 200 characters, that has to frighten a reader in one breath: an ultrasound finds two heartbeats, and the second one is beating from inside the wall behind the bed. The program writes that sentence to `/output/entry.txt`. It is fully deterministic — the same line, the same bytes, on every run — with a length guard that fails loudly if the line ever falls outside the 1–200 character gate, and a read-back check that verifies what was written.

## Run it

```sh
node main.ts
```
